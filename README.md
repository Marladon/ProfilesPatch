# xilab_cfg_tool

GUI утилита для работы с `.cfg` файлами профилей XILab / mDrive.

## Возможности

- **Patch** — миграция профилей под новую версию протокола без запуска XILab
- **Replace** — поиск и замена значений в профилях через регулярные выражения

## Требования

- Python 3.6+
- Стандартная библиотека (никаких `pip install`)

## Запуск

Двойной клик по `xilab_cfg_tool.bat` (оба файла должны лежать рядом), или:

```bash
python xilab_cfg_tool.py
```

## Вкладка Patch

Добавляет в `.cfg` файлы новые ключи появившиеся в обновлённой версии протокола.

### Как работает

1. Парсит `motorsettings.cpp` и `stagesettings.cpp` из репозитория XILab
2. Извлекает все ключи которые XILab записывает при сохранении (`setValue` + `SAVE_KEY`)
3. Для каждого `.cfg` добавляет отсутствующие ключи с дефолтными значениями
4. Сохраняет статус верификации каждого файла:
   - файл был **верифицирован** → хэш пересчитывается, файл остаётся верифицированным
   - файл был **не верифицирован** → хэш не трогается

Файлы с актуальными ключами не изменяются.

### Опция --rehash

Чекбокс `--rehash` форсирует пересчёт хэша для всех файлов включая намеренно невалидные.

### При обновлении протокола

Ничего менять не нужно — просто указывай путь до обновлённого репозитория XILab. Скрипт сам читает актуальные исходники и находит новые ключи.

> Ключи в `motorsettings.cpp` / `stagesettings.cpp` — единственный источник истины.
> `protocol.xi` из libximc определяет структуры протокола, но маппинг в INI-ключи живёт только в XILab.

## Вкладка Replace

Интерактивный поиск и замена значений через регулярные выражения.

### Как работает

1. Вводишь регулярное выражение → **Preview** показывает все совпадения по файлам
2. Вводишь строку замены → **Replace** применяет изменения
3. Верификация обрабатывается автоматически:
   - файл был **верифицирован** → хэш пересчитывается
   - файл был **не верифицирован** → не трогается

Кнопка Replace заблокирована до нажатия Preview — чтобы не применять замену вслепую.

### Пример

Найти все ненулевые значения `timeout_4` и обнулить:

```
Регулярное выражение:  (timeout_4\s*=\s*)[1-9]\d*
Замена:                timeout_4=0
```

## Технические детали

`.cfg` файлы — стандартный INI формат (Qt QSettings). Секция `[VERIFICATION]` содержит MD5 хэш содержимого файла без самой этой секции. Хэш считается от текста в UTF-8 с нормализованными переносами строк `\n`, точно как в XILab (`QFile::Text` + `QCryptographicHash::Md5`).

Статус верификации определяется **до** внесения изменений: если хэш в `[VERIFICATION]` совпадает с реальным — файл верифицирован и хэш пересчитывается после правки. Если не совпадает — хэш остаётся нетронутым.
